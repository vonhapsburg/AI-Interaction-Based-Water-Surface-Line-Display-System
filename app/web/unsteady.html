一个必须说清的理论限制：扩散波是抛物型方程，扰动传播速度在数学上是无穷大， 所以本页不能演示"急流时下游扰动传不上去"这类特征线现象——那需要双曲型的全圣维南方程。 另外，稳态回归的偏差主要来自扩散波对回水的线性化近似（非数值误差）。
公式速查 本页用到的方程与离散
连续方程∂A/∂t + ∂Q/∂s = 0
即 B·∂h/∂t + ∂Q/∂s = 0（B 为水面宽）
动量方程（全方程）∂Q/∂t + ∂(Q²/A)/∂s + gA∂h/∂s + gA(S_f − i₀) = 0
工程模式保留全部惯性项
扩散波（教学模式）Q = K·√(i₀ − ∂h/∂s)，K = A·R^(2/3)/n
忽略惯性项，得抛物型方程
运动波速c_k = dQ/dA = (5/3)·v
仅宽浅矩形成立；梯形需数值求导
特征线ds/dt = v ± c，c = √(gA/B)
缓流可上溯的扰动速度就是 c − v
Preissmann 四点隐式f ≈ ψf_{i+1} + (1−ψ)f_i；∂f/∂t ≈ [ψΔf_{i+1} + (1−ψ)Δf_i]/Δt
θ 控制时间加权，本页 θ=0.7、ψ=0.5
回水长度L_b ≈ (h − h₀) / i₀
界面显示的是「抬升降到 5% 抬升量」处的实际长度
坦化与绳套∂h/∂t ≠ 0 ⇒ 附加比降 ≠ 0 ⇒ h(Q) 多值
涨水段同一 Q 下 h 偏低，落水段偏高，于是成环
断面比能E_s = h + αv²/(2g)
临界流时 E_s 取极小值
弗劳德数Fr = v / √(gA/B)
Fr<1 缓流、Fr=1 临界、Fr>1 急流
临界水深条件Q²B/(gA³) = 1
矩形渠：h_c = (Q²/(gb²))^(1/3)
