能力边界（必读）：本页求解扩散波——连续方程 + 完整阻力项 + 压力项， 忽略惯性项（当地加速度、迁移加速度），即教材 8.10.3 的「瞬时流态法」。 适用于缓变洪水演进；不支持溃坝、涌潮、闸门急变等强非恒定工况（需全圣维南方程 + 激波捕捉）。 断面限矩形/梯形棱柱体；边界限上游流量过程线与下游给定水位。
一个必须说清的理论限制：扩散波是抛物型方程，扰动传播速度在数学上是无穷大， 所以本页不能演示"急流时下游扰动传不上去"这类特征线现象——那需要双曲型的全圣维南方程。 另外，稳态回归的偏差主要来自扩散波对回水的线性化近似（非数值误差）。
公式速查 本页用到的方程与离散
连续方程∂A/∂t + ∂Q/∂s = 0
即 B·∂h/∂t + ∂Q/∂s = 0（B 为水面宽）
动量方程（全方程）∂Q/∂t + ∂(Q²/A)/∂s + gA∂h/∂s + gA(S_f − i₀) = 0
工程模式保留全部惯性项
扩散波（教学模式）Q = K·√(i₀ − ∂h/∂s)，K = A·R^(2/3)/n
忽略惯性项，得抛物型方程
运动波速c_k = dQ/dA = (5/3)·v
仅宽浅矩形成立；梯形需数值求导
特征线ds/dt = v ± c，c = √(gA/B)
缓流可上溯的扰动速度就是 c − v
Preissmann 四点隐式f ≈ ψf_{i+1} + (1−ψ)f_i；∂f/∂t ≈ [ψΔf_{i+1} + (1−ψ)Δf_i]/Δt
θ 控制时间加权，本页 θ=0.7、ψ=0.5
