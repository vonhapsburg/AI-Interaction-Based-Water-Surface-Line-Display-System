# 基于AI交互的水面线展示系统

> 明渠非均匀流十二型水面曲线的自然语言计算与可视化

用户用一句话（或参数表单）描述一条棱柱体明渠，系统判别水面曲线类型（M₁/M₂/M₃、S₁/S₂/S₃、C₁/C₃、H₂/H₃、A₂/A₃），推算沿程水深，定位水跃与水跌，并在网页中绘出纵剖面图与横断面图。

**人工智能只负责把自然语言解析成参数，不参与任何数值计算。** 所有水力数值均来自自建的 `gvf_core.py` 计算内核。

---

## 一、架构

```
浏览器（HTML + Canvas，无外部依赖）
   │  HTTP / JSON
   ▼
server.py（本地服务）
   ├─ agent/    规则解析 → 本地模型补缺 → 增量合并 → 参数适配 → 合法性判定
   └─ gvf_core.py   计算内核（唯一数值来源）
```

| 层 | 文件 | 职责 |
|---|---|---|
| 计算内核 | `app/gvf_core.py` | 断面几何、h₀/h_c/i_c、十二型判别、RK4 积分、水跃水跌、折线变坡衔接 |
| 参数层 | `app/agent/parser.py` | 中文口语 → 结构化参数（纯正则，毫秒级） |
| 参数层 | `app/agent/llm.py` | 本地 qwen3:4b 单句抽取（JSON Schema 约束） |
| 参数层 | `app/agent/merge.py` | 双通道合并；`turn()` 维护跨轮会话槽位表 |
| 参数层 | `app/agent/adapter.py` | 槽位 → `gvf_core.Params`，越界拦截 |
| 参数层 | `app/agent/legality.py` | 输入合法性 A~I 判定 |
| 展示层 | `app/web/index.html` | 纵剖面、横断面、结果卡、力学依据、历史回放 |

**单一真源**：页面与 AI 层都不产生数值。`app/gvf_core.py` 与仓库根目录的 `gvf_core v1.1.0.py` SHA256 完全一致。

## 二、本地运行（开发模式）

需要 Python 3.10+ 与 numpy：

```bash
pip install numpy
cd app
python server.py
```

打开 <http://127.0.0.1:8000>。

### 模型通道（三选一）

自然语言解析需要一个语言模型；**计算本身不依赖它**，任何配置下计算、绘图、历史、导出都一致。

**① DeepSeek API（默认）** —— 复制 `app/config.example.ini` 为 `app/config.ini`：

```ini
[llm]
provider = deepseek
model = deepseek-chat
api_key = sk-你的密钥
```

或用环境变量 `DEEPSEEK_API_KEY`（优先级更高）。密钥只在服务端使用，不会进入前端；
`config.ini` 已在 `.gitignore` 中。

**② 本地 Ollama** —— 把 `provider` 改成 `ollama`，并准备模型：

```bash
ollama pull qwen3:4b
```

**③ 关闭** —— `provider = none`，只用规则解析（毫秒级，覆盖常见句式）。

未配置或调用失败时，系统自动退回规则通道并在界面提示，不会中断计算。

## 四、功能要点

- **十二型判别**：按 h 与 h₀、h_c 的位置关系分区，标注曲线型号、流态与推算方向；
- **折线变坡**：段内棱柱体，段间底坡突变、渠底高程连续；缓转陡设临界控制，陡转缓按共轭水深求交定位水跃；
- **水跃 / 水跌**：共轭水深、跃型、跃长（吴持恭 / 欧勒弗托斯基 / 陈椿庭三式）、消能系数；
- **自然语言**：一句话出图，支持逐句补参数（会话槽位表）与「改成 / 换成」式修改；
- **参数表单**：多段渠段表、渠首 / 渠末条件、预设算例、双模式（教学 α=1.00 / 工程 α=1.05）；
- **力学依据面板**：逐条给出判别过程（i 与 i_c 比较、h 与 h₀/h_c 比较、推算方向）；
- **历史回放**：SQLite 记录每次计算，点击即用当时参数重算并还原图形。

## 五、边界与局限

1. 仅明渠恒定渐变流，不含非恒定流；
2. 断面仅矩形与梯形，不支持三角形、圆形（圆形 h₀ 可能双解）；
3. 折线变坡、段内棱柱体，不支持断面沿程连续变化的非棱柱体渠道；
4. 段间渠底高程连续，不处理台阶跌坎与窒息判定；
5. 全渠流量不变，无侧向入流与分流；
6. 弯段、复式断面、天然河道不支持；
7. 梯形断面水跃能量损失与跃长采用矩形公式近似，仅作量级参考；
8. 自然语言解析在单位混用或长句上仍有失败可能，可改用参数表单。
