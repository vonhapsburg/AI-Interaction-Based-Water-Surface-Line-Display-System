# 基于AI交互的水面线展示系统

> 明渠非均匀流十二型水面曲线的自然语言计算与可视化

用户用一句话（或参数表单）描述一条棱柱体明渠，系统判别水面曲线类型（M₁/M₂/M₃、S₁/S₂/S₃、C₁/C₃、H₂/H₃、A₂/A₃），推算沿程水深，定位水跃与水跌，并在网页中绘出纵剖面图与横断面图。

**人工智能只负责把自然语言解析成参数，不参与任何数值计算。** 所有水力数值均来自自建的 `gvf_core.py` 计算内核。

## 一、架构

```
浏览器（HTML + Canvas，无外部依赖）
   │  HTTP / JSON
   ▼
server.py（本地服务）
   ├─ agent/    规则解析 → 本地模型补缺 → 增量合并 → 参数适配 → 合法性判定
   └─ gvf_core.py   计算内核（唯一数值来源）
```

| 层 | 文件 | 职责 |
|---|---|---|
| 计算内核 | `app/gvf_core.py` | 断面几何、h₀/h_c/i_c、十二型判别、RK4 积分、水跃水跌、折线变坡衔接 |
| 参数层 | `app/agent/parser.py` | 中文口语 → 结构化参数（纯正则，毫秒级） |
| 参数层 | `app/agent/llm.py` | 模型通道：DeepSeek API / 本地 Ollama / 关闭，单句抽取（JSON Schema 约束）+ 自由对话 |
| 参数层 | `app/agent/merge.py` | 双通道合并；`turn()` 维护跨轮会话槽位表，支持「第2段」定位 |
| 参数层 | `app/agent/adapter.py` | 槽位 → `gvf_core.Params`，越界拦截 |
| 参数层 | `app/agent/legality.py` | 输入合法性 A~I 判定 |
| 对话层 | `app/agent/chat.py` | 自由问答：能力、概念、用法、结果解释（不产生数值） |
| 生成层 | `app/agent/generator.py` | 随机生成"保证出现水跃/水跌/指定型号"的算例，先内核验证再返回 |
| 预设层 | `app/presets_catalog.json` | 12 型 + 坡度组合 + 典型现象，每条均由 `tools/build_catalog.py` 验证生成 |
| 展示层 | `app/web/index.html` | 纵剖面、横断面、结果卡、力学依据、历史回放、示例算例面板 |

**单一真源**：页面与 AI 层都不产生数值，全部水力数值来自 `app/gvf_core.py`。

> 内核基线：`gvf_core v1.1.0.py` 为原始版本。之后修复了 4 处非数值缺陷（平/负坡接陡坡的事件命名、
> 无重叠区间的水跃告警、多跃位检测告警、梯形水跃损失备注措辞），并用 58 个算例的逐字段快照
> （`tests/golden_snapshot.py`）证明**数值结果 0 处变化**。
>
> 多水跃：已支持"坡折临界之后的第二段急流"这一常见情形（`_fill_critical_gaps`）：
> 把上游急流链延长到坡折临界点、从该点再起一条急流链，并与下游缓流链对撞求跃。
> 实测四段交替算例由"缺口 + W_GAP"变为"全程覆盖 + 临界衔接 + 水跃"，其余 57 个算例逐字段不变；
> 任意交替的复杂多跃位仍需逐段推进式求解器，未包含在本版内。

## 二、主要功能

- **一句话计算**：自然语言 → 参数 → 内核计算 → 出图，缺参数时会记住已说的、只提示还差什么；
- **十二型全覆盖**：示例算例面板内置 M1/M2/M3、S1/S2/S3、C1/C3、H2/H3、A2/A3 共 12 条，点一下直接复现；
- **坡度组合**：缓→缓、陡→陡、缓→陡（坡折临界）、陡→缓（含水跃）；
- **水跃与水跌**：典型现象预设，并可**随机生成**——参数由搜索器在真实内核上试算，
  确认结果里确实出现水跃/水跌才返回（模型不参与数值）；
- **多段变坡**：段内棱柱体、段间折线衔接，坡折处自动判别临界/水跃/水跌；
- **对话能力**：可以问"你会什么""什么是临界水深""这个工况为什么是 M1"，
  也可以说"给我一个发生水跃的样例"；提问不会改动当前参数，试算结果需点按钮才应用；
- **可追溯**：结果卡给出力学依据（i vs i_c、h vs h₀/h_c、流区、推算方向），
  支持历史回放与 CSV 导出。

## 二、本地运行（开发模式）

需要 Python 3.10+ 与 numpy：

```bash
pip install numpy
cd app
python server.py
```

打开 <http://127.0.0.1:8000>。

### 模型通道（三选一）

自然语言解析需要一个语言模型；**计算本身不依赖它**，任何配置下计算、绘图、历史、导出都一致。

**① DeepSeek API（默认）** —— 复制 `app/config.example.ini` 为 `app/config.ini`：

```ini
[llm]
provider = deepseek
model = deepseek-chat
api_key = sk-你的密钥
```

或用环境变量 `DEEPSEEK_API_KEY`（优先级更高）。密钥只在服务端使用，不会进入前端；
`config.ini` 已在 `.gitignore` 中。

**② 本地 Ollama** —— 把 `provider` 改成 `ollama`，并准备模型：

```bash
ollama pull qwen3:4b
```

**③ 关闭** —— `provider = none`，只用规则解析（毫秒级，覆盖常见句式）。

未配置或调用失败时，系统自动退回规则通道并在界面提示，不会中断计算。

## 四、功能要点

- **十二型判别**：按 h 与 h₀、h_c 的位置关系分区，标注曲线型号、流态与推算方向；
- **折线变坡**：段内棱柱体，段间底坡突变、渠底高程连续；缓转陡设临界控制，陡转缓按共轭水深求交定位水跃；
- **水跃 / 水跌**：共轭水深、跃型、跃长（吴持恭 / 欧勒弗托斯基 / 陈椿庭三式）、消能系数；
- **自然语言**：一句话出图，支持逐句补参数（会话槽位表）与「改成 / 换成」式修改；
- **参数表单**：多段渠段表、渠首 / 渠末条件、预设算例、双模式（教学 α=1.00 / 工程 α=1.05）；
- **力学依据面板**：逐条给出判别过程（i 与 i_c 比较、h 与 h₀/h_c 比较、推算方向）；
- **历史回放**：SQLite 记录每次计算，点击即用当时参数重算并还原图形。

## 五、边界与局限

恒定流部分（本页主功能）：

1. 仅明渠恒定渐变流，不含非恒定流；
2. 断面仅矩形与梯形，不支持三角形、圆形（圆形 h₀ 可能双解）；
3. 折线变坡、段内棱柱体，不支持断面沿程连续变化的非棱柱体渠道；
4. 段间渠底高程连续，不处理台阶跌坎与窒息判定；
5. 全渠流量不变，无侧向入流与分流；
6. 弯段、复式断面、天然河道不支持；
7. 梯形断面水跃能量损失与跃长采用矩形公式近似，仅作量级参考；
8. 自然语言解析在单位混用或长句上仍有失败可能，可改用参数表单。

**非恒定流实验（独立模块，`/unsteady.html`）** 的能力边界见第八节。

## 八、非恒定流实验（方案 A：扩散波）

独立模块，**不改动恒定流内核与主界面**：`unsteady/` 目录 + `/unsteady.html` 页面 + `/api/unsteady/run` 接口。

**模型**（教材 8.10.3「瞬时流态法」）：

```
连续：B·∂h/∂t + ∂Q/∂s = 0
运动：忽略惯性项，Q = K(h)·√(i₀ − ∂h/∂s)，K = A·R^(2/3)/n
```

即**扩散波**：保留波速与坦化，能算出"一族水面线 / 洪峰削峰展宽滞后 / 水位-流量绳套"，
但**不能**算溃坝、涌潮、闸门急变（需全圣维南 + 激波捕捉）。

**验证结果**（`step20_unsteady.py`，21 项全过）：

| 检验 | 结果 |
|---|---|
| 质量守恒 | 相对误差 **0.000%** |
| 稳态回归（与 `gvf_core` 对比，M1 型壅水） | 平均 **0.38%**，最大 2.12% |
| 小扰动波速 vs L/c_k | 偏差 **−3.9%** |
| 削峰/滞后 | 峰值沿程单调下降、峰现时刻单调增大 |
| 恒定流回归 | `/api/solve` 结果不变（M2→S2） |

**5/3 的适用条件**也做了数值验证：宽浅矩形（b/h>100）时 c_k/v=1.66；b=5 m 时严格曼宁给出 1.46——
所以"洪峰比水质点快 1.67 倍"只对宽浅矩形成立，界面上直接标出了实际比值。

### 8.1 两个求解器（页面左上切换）

| | 扩散波 A | 全方程 B1 |
|---|---|---|
| 方程 | 连续 + 压力 + 阻力，忽略惯性项 | 完整圣维南（含惯性项） |
| 数值 | 显式推进，Δt≈1 s | Preissmann 四点隐式 + Newton，Δt≈30 s |
| 回水顶托 | 近似 | ✅ 正确 |
| 下游扰动上溯 | 数学上无穷速 | ✅ 按 c−v 传播 |
| 溃坝/涌潮 | ❌ | ❌（需方案 C） |
| 代码 | unsteady/solver.py | unsteady/preissmann.py |

B1 验收（step22_preissmann.py，15 项）：

| 判据 | 实测 |
|---|---|
| 恒定极限 vs gvf_core | 平均 **0.15%**、最大 **0.36%** |
| 质量守恒 | **0.005%** |
| 回水逆传速度 vs (c−v) | 偏差 **+1.4%** |
| Newton 失败次数 | **0** |
| 6 h 模拟耗时 | 约 **0.2–3 s**（Nx=61，Δx=83 m） |

### 8.2 教学模式 / 工程模式

非恒定流页与恒定流页使用同一套模式语义：

| 模式 | 求解器 | 用途 |
|---|---|---|
| 教学模式 | 扩散波 A（忽略惯性项） | 讲清一族曲线、削峰、绳套；约 1 s |
| 工程模式 | 圣维南全方程 B1（Preissmann 隐式） | 回水顶托、下游扰动上溯；约 1–3 s |

切换按钮在页面左上角，默认教学模式；头部副标题与诊断栏会同步变化。

### 8.3 对话交互（AI + 力学）

非恒定页新增对话框（unsteady/chat.py + /api/unsteady/chat）：

- **说工况**：「渠长5公里，底宽5米，流量从10涨到30，1小时涨完，2小时回落，模拟6小时」
  → 解析成参数、回填表单并自动计算；
- **问机理**：「为什么洪峰变矮了」「绳套为什么是逆时针」
  → 只用当前结果里的数字，配合连续方程、扩散项、c_k、c−v 解释；
- **出练习**：「出几道题」→ 3 道题 + 答案 + 解析。

模型只负责语言与参数解析，**不产生任何水力数值**；数值仍全部来自内核。
